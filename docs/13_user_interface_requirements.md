# UI 横断要件

本書は特定の画面・機能に閉じない、UI 全体で一貫させるべき規約を定める。新規に追加するクライアント側 UI はここに記載する規約に従うこと（[CLAUDE.md](../CLAUDE.md) の横断ルール運用方針を参照）。

## 破壊的操作の確認

### 破壊的操作の共通確認パターン

**UID**: UI-01-01 \
**STATUS**: Active

以下はいずれも取り消しがコマンドスタック (SP-05-03) の範囲外、またはユーザーの入力作業を失わせる操作であり、実行前に確認ダイアログを要する。

| 操作 | 理由 |
|---|---|
| プロジェクトの破棄 (API-01-03) | サーバ側の一時状態を失う |
| gpkg の再アップロード（既存プロジェクトの置き換え） | 現在のオーバーライドとの整合性が崩れうる |
| 保存データを読み込まずに離脱（未保存の変更がある場合） | 手動調整 (RQ-05-05) を失う |
| 個別のオーバーライドの一括リセット | 手動調整をすべて失う（ノード単位の移動の Undo は対象外。SP-05-03 の通常操作） |

これらは共通のコンポーネント `DeleteButton`（確認モーダル＋ラベル付き確定ボタンを内包）を通して実装し、個別に独自の `confirm()` 呼び出しやカスタムダイアログを実装しない。`DeleteButton` は破壊対象の名称を確認文言に埋め込む（例:「"山田家系図.gpkg" を破棄しますか？」）。

### 通常操作との区別

**UID**: UI-01-02 \
**STATUS**: Active \
**RELATIONS**:
- **Type**: Parent
  **ID**: RQ-05-06

ノード移動・表示項目切替・枝の表示/非表示・自動レイアウトの再実行は、コマンドスタックで Undo 可能なため UI-01-01 の確認対象に **含めない**。確認ダイアログの濫用は Undo の価値を損なうため、「Undo で復元できる操作」と「復元できない操作」を UI 設計時に明確に区別すること。

**STATUS**: Active \

Undo/Redo ボタンは編集ビューの常設ツールバーに常時表示し、直前の操作内容をラベル（例:「元に戻す: ノード移動」）として示す。キーボードショートカット（`Ctrl+Z` / `Ctrl+Y`）も併用可能とする。

## 設定パネルの構成

### パネルの分類

**UID**: UI-03-01 \
**STATUS**: Active \
**RELATIONS**:
- **Type**: Parent
  **ID**: RQ-03-12
- **Type**: Parent
  **ID**: RQ-06-01
- **Type**: Parent
  **ID**: RQ-06-02
- **Type**: Parent
  **ID**: RQ-06-03
- **Type**: Parent
  **ID**: RQ-05-03
- **Type**: Parent
  **ID**: RQ-07-02

設定は以下 3 パネルに分類し、単一の折りたたみ式サイドパネルにタブ切り替えで収める。

| パネル | 内容 |
|---|---|
| スタイル | 書体・暦・配色・人物枠・標題（位置を含む）・表示項目トグル |
| 表示範囲 | 起点人物・枝の表示/非表示・基準人物 |
| 印刷 | 用紙サイズ・向き・余白・系統分割・A4 タイル設定 |

### 変更の即時反映

**UID**: UI-03-02 \
**STATUS**: Active

スタイルパネル・表示範囲パネルでの変更は、明示的な「適用」操作なしにキャンバスへ即時反映する。標題位置は上部ツールバーのドロップダウンから右側・縦書き／上部・横書きを切り替え、即時反映する。印刷パネルのみ、印刷ビューへの切替 (SP-07-01) を経て確認する。

## 縦書き表示のフォールバック

### 横書き表示への切替導線

**UID**: UI-04-01 \
**STATUS**: Active \
**RELATIONS**:
- **Type**: Parent
  **ID**: RQ-02-08

縦書き表示 (RQ-02-01) を既定としつつ、スタイルパネルから横書きへ即座に切り替えられる導線を常設する。縦書き CSS (`writing-mode: vertical-rl`) 非対応のブラウザ環境を利用者が使用している場合の代替手段として機能させる。

## 状態表示

### gpkg 読み込みエラーの表示

**UID**: UI-05-01 \
**STATUS**: Active \
**RELATIONS**:
- **Type**: Parent
  **ID**: RQ-01-09

API-00-02 のエラー応答を、`code` に応じた日本語メッセージへ変換して表示する。部分的なデータ欠損（RQ-01-09 が許容する範囲）は処理を継続し、エラーではなく画面上の非侵襲的な通知（トースト等）で件数を示すに留める。

### 長時間処理中のフィードバック

**UID**: UI-05-02 \
**STATUS**: Active

gpkg アップロード・レイアウト再計算・PDF エクスポートなど、体感的に待ち時間が発生しうる操作にはローディング表示を伴わせる。
